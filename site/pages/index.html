What happens when you choose a mixture

  1. Describe

    Two compounds, a model and one condition become a short input file. Properties come from a database of published values.

  2. Check

    The program decides whether that information is enough, which calculation it implies, and what is missing if not.

  3. Model

    An equation of state or an activity model gives the fugacity of each compound in the liquid and in the vapor.

  4. Solve and plot

    Equilibrium is where each compound's fugacity is the same in both phases. Sweeping that condition draws the diagram.
