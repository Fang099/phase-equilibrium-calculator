What the tool does

This is a course project for Chemical Engineering Thermodynamics. The reference text is Thermodynamics and Its Applications by Tester and Modell. The tool takes a description of a mixture in plain text, decides what can be calculated from it, solves the equilibrium conditions, and reports phase compositions, saturation points, phase diagrams and, in a field, profiles of pressure and composition with position.

Most phase-equilibrium software assumes the right data are available and stops with an error when they are not. This tool starts one step earlier: given whatever the user knows (critical constants, vapor pressures, latent heats, melting points), it works out which equilibria are calculable, which calculation the given variables imply, and exactly what is missing for the rest.

Every result traces back to one place: the fundamental equation, written in its Helmholtz form, and the criterion that chemical potentials are equal in coexisting phases. Cubic equations of state, latent-heat relations and external fields all enter through that same route, so there is one equilibrium solver for all of them.

Theory

This section follows the structure of Tester and Modell: start from the fundamental equation, derive the equilibrium criteria and the phase rule, and then choose a model that supplies the chemical potentials. Notation may differ slightly from the book.

The fundamental equation and why the Helmholtz form

For a simple system of \(n\) components, the fundamental equation in energy form is

\[ dU = T\,dS - P\,dV + \sum_{i=1}^{n} \mu_i\,dN_i . \]

Its Legendre transforms contain exactly the same information in different natural variables. The tool uses the Helmholtz energy \(A = U - TS\):

\[ dA = -S\,dT - P\,dV + \sum_{i} \mu_i\,dN_i , \qquad P = -\left(\frac{\partial A}{\partial V}\right)_{T,\mathbf N}, \qquad \mu_i = \left(\frac{\partial A}{\partial N_i}\right)_{T,V,N_{j\neq i}} . \]

The reason is practical. A cubic equation of state gives pressure as a function of \(T\), \(V\) and composition, which are exactly the natural variables of \(A\). One integration over volume turns the equation of state into a complete fundamental relation, and everything else is obtained by differentiation. \(U\) is used for the derivations themselves; the Gibbs form appears where its natural variables \(T, P\) fit better, in the latent-heat route below.

Equilibrium criteria and the phase rule

Maximizing entropy (equivalently, minimizing \(A\) at fixed \(T\) and \(V\)) for phases that can exchange energy, volume and matter gives uniform \(T\) and \(P\), and equal chemical potentials of every component in every phase. Written with fugacities, which is the form the solver uses:

\[ \mu_i^{\alpha} = \mu_i^{\beta} \quad\Longleftrightarrow\quad \hat f_i^{\alpha}(T,P,\mathbf x^{\alpha}) = \hat f_i^{\beta}(T,P,\mathbf x^{\beta}) . \]

Each phase has \(n+2\) independent variables, one fewer for its intensive state by the Gibbs–Duhem equation. An external field adds one work term per field, so \(m\) more. Subtracting the equilibrium constraints from the variables gives the number of intensive variables that can be fixed independently:

\[ F = n + 2 + m - \pi . \]

For a closed system with a known feed composition, Duhem's theorem applies instead: \(2 + m\) variables fix the state. The input checker uses these counts, with \(m = 1\) when a gravity or centrifugal field is present.

Cubic equations of state in Helmholtz form

The three cubic equations share one form, differing only in two constants and in how \(a\) depends on temperature:

\[ P = \frac{RT}{v-b} - \frac{a(T)}{(v+\delta_1 b)(v+\delta_2 b)} \]
Model\(\delta_1,\ \delta_2\)\(a(T)\)Pure-component data
van der Waals0, 0constant\(T_c, P_c\) or \(a, b\)
Soave–Redlich–Kwong1, 0\(a_c\,[1+m(1-\sqrt{T/T_c})]^2\), \(m = 0.480 + 1.574\omega - 0.176\omega^2\)\(T_c, P_c, \omega\)
Peng–Robinson\(1+\sqrt2,\ 1-\sqrt2\)same form, \(m = 0.37464 + 1.54226\omega - 0.26992\omega^2\)\(T_c, P_c, \omega\)

For mixtures, the van der Waals one-fluid mixing rules apply, with one binary interaction parameter per pair:

\[ a = \sum_i\sum_j x_i x_j \sqrt{a_i a_j}\,(1-k_{ij}), \qquad b = \sum_i x_i b_i . \]

Integrating \(P - NRT/V\) over volume from the ideal-gas limit gives the residual Helmholtz energy in closed form,

\[ \frac{A^{\mathrm{res}}}{NRT} = -\ln\!\left(1-\frac{b}{v}\right) - \frac{a}{bRT(\delta_1-\delta_2)}\,\ln\frac{v+\delta_1 b}{v+\delta_2 b} \qquad\left(\text{van der Waals: } -\frac{a}{RTv}\right), \]

and the fugacity coefficient of each component is one derivative of it:

\[ \ln\hat\varphi_i = \left(\frac{\partial\,(A^{\mathrm{res}}/RT)}{\partial N_i}\right)_{T,V,N_{j\neq i}} - \ln Z , \qquad \hat f_i = x_i\,\hat\varphi_i\,P . \]

At a given \(T\) and \(P\), the cubic in \(Z\) can have three real roots. The smallest is used for a liquid, the largest for a vapor, and the root with the lower Gibbs energy when the phase is not known.

When there is no equation of state: the latent-heat route

Some components cannot be described by a cubic equation of state. Sucrose decomposes before it boils, so it has no meaningful critical point. For these cases the tool uses the Gibbs-energy route with an ideal liquid solution:

\[ \hat f_i^{L} = x_i\, f_i^{L}, \qquad f_i^{L} = P_i^{\mathrm{sat}} \exp\!\left[\frac{V_i^{L}\,(P-P_i^{\mathrm{sat}})}{RT}\right], \qquad \hat f_i^{V} = y_i P . \]

The vapor pressure comes from whichever source the user gave: Antoine constants, a typed relation \(P^{\mathrm{sat}}(T)\), or the Clausius–Clapeyron equation from the normal boiling point and enthalpy of vaporization. For a pure solid, the Gibbs–Helmholtz equation integrated from the melting point gives its fugacity relative to the pure liquid:

\[ \ln\frac{f_i^{S}}{f_i^{L}} = -\frac{\Delta H_{\mathrm{fus}}}{R}\left(\frac1T - \frac1{T_m}\right) + \frac{\Delta C_p}{R}\left(\frac{T_m}{T} - 1 - \ln\frac{T_m}{T}\right). \]

A non-volatile solute never enters the vapor, so its pure-liquid reference fugacity is never needed in absolute terms: it appears on both sides of its solid–liquid equation and cancels. That is why sugar–water can be calculated from latent heats and melting points alone.

External fields

A gravity or centrifugal field does work on the mass of the system, so the fundamental equation gains a term \(\Phi\,dm\), with \(m = \sum_i M_i N_i\). The potential per unit mass is

\[ \Phi_{\text{gravity}} = g\,(z - z_{\mathrm{ref}}), \qquad \Phi_{\text{centrifugal}} = -\tfrac12\,\omega^2\,(r^2 - r_{\mathrm{ref}}^2) . \]

The equilibrium criterion becomes: temperature is uniform, and \(\mu_i + M_i\Phi\) is the same everywhere. In fugacities,

\[ \ln \hat f_i(T, P, \mathbf x) + \frac{M_i\,\Phi}{RT} = \text{constant throughout the system}. \]

Three consequences follow, and the tool shows each one.

The local phase diagram does not change. Two phases that coexist at one position have the same \(\Phi\), so the field term cancels between them. The Pxy diagram at the bottom of a column is the ordinary one.

Pressure varies hydrostatically, without being imposed. Summing \(x_i\,d\mu_i = -x_i M_i\,d\Phi\) and using the Gibbs–Duhem equation at constant temperature, \(\sum_i x_i\,d\mu_i = v\,dP\), gives \(dP = -\rho\,d\Phi\). The solver never uses this equation, yet its profiles satisfy it to about \(10^{-7}\) bar.

Composition varies with position, and phases can appear. The heavier component concentrates where \(\Phi\) is lowest. If the falling pressure brings the local fluid to saturation, a second phase forms there: a gas cap at the top of a tall liquid column, for example.

Numerical methods

Vapor–liquid. With \(K_i = y_i/x_i = \hat\varphi_i^{L}/\hat\varphi_i^{V}\), a material balance on a feed \(\mathbf z\) split into a vapor fraction \(\beta\) gives the Rachford–Rice equation,

\[ \sum_i \frac{z_i\,(K_i-1)}{1+\beta\,(K_i-1)} = 0 . \]

Setting \(\beta = 0\) gives a bubble point and \(\beta = 1\) a dew point, so one routine handles both, solving for the unknown \(T\) or \(P\) with Brent's method. Because \(K\) depends on the phase compositions, it is updated by successive substitution until it stops changing. Starting values come from Wilson's correlation, \(K_i \approx (P_{c,i}/P)\exp[5.373(1+\omega_i)(1-T_{c,i}/T)]\). A solution with \(\mathbf x = \mathbf y\) (the trivial solution near a critical point) is detected and reported rather than returned.

Solid–liquid. One equation, \(\hat f_i^{L} = f_i^{S}\), solved for temperature or composition. The eutectic is the composition where the two liquidus curves meet.

Field profiles. At each position, the field equation above is solved for \(\ln P\) and the free mole fractions. The march starts at the reference position, uses the hydrostatic estimate \(P - \rho\,\Delta\Phi\) as the first guess, and halves any step that fails. After each step, the local fluid is tested against its own bubble or dew pressure. When saturation is crossed, the contact is located by bisection and the march continues in the new phase.

Describing a system

The user writes down what they know, one quantity per line, in any order, with units. Lines starting with # are comments. This is the instructor's sugar–water example:

components = water, sucrose
P = 1 atm
sweep = x                      # draw the full diagram in composition
water.Tb = 373.15 K
water.dHvap = 40.65 kJ/mol
water.Tm = 273.15 K
water.dHfus = 6.01 kJ/mol
sucrose.nonvolatile = yes
sucrose.Tm = 459 K
sucrose.dHfus = 46 kJ/mol

Property values in the examples are typical literature values for demonstration. Take your own from the appendix of Tester and Modell or another cited source.

What the checker reports

For every possible equilibrium (vapor–liquid, plus solid–liquid for any component with a melting point), the checker writes out the fundamental relation, chooses how each chemical potential will be calculated, counts the degrees of freedom, and gives a verdict:

SUFFICIENT
The data and the state specification are complete. It names the calculation, for example "Txy diagram at fixed P".
INSUFFICIENT
Lists what is missing, with alternatives (for example, either the acentric factor for the equation of state or vapor pressures for the ideal-solution route), and suggests valid specifications.
OVERSPECIFIED
More intensive variables were fixed than the phase rule allows. It says how many to remove.
INVALID
The input itself is wrong: an unknown quantity (with a spelling suggestion), mole fractions that do not add up to 1, an unknown unit.

Worked examples

All numbers and charts on this page are computed by the tool itself (scripts/make_docs_data.py), using the files in examples/.

Propane / n-butane with three equations of state

The diagram at the top of the page is the Peng–Robinson Pxy diagram at 300 K with \(k_{ij} = 0.003\). At \(x_{\text{propane}} = 0.4\), the bubble pressure is bar and the first vapor contains propane. The ends of the diagram are the vapor pressures of the pure components, so the three equations of state can be compared directly on pure propane:

The van der Waals equation, with no acentric factor and a temperature-independent \(a\), is far off. SRK and PR, which fit \(a(T)\) to vapor-pressure behavior through \(\omega\), are within about 1%.

Sugar–water at 1 atm

Three equilibria from latent heats and melting points alone: boiling (liquid + water vapor), freezing (liquid + ice) and solubility (liquid + solid sucrose). At \(x_{\text{water}} = 0.95\), about 50 wt% sucrose, the ideal-solution model gives a boiling point of K and a freezing point of K.

The ideal solution model treats sucrose and water as if they mixed like similar molecules. Real sugar solutions are strongly non-ideal, which is why the solubility curve here is unrealistic. The calculation is still a useful check: the boiling-point elevation and freezing-point depression near pure water follow the textbook dilute-solution results.

Gravity: a 500 m column of propane / n-butane

A liquid with \(z_{\text{propane}} = 0.4\) at 320 K and 25 bar sits at the bottom of a 500 m column. Moving up, the pressure falls hydrostatically. At m the pressure reaches the local bubble pressure ( bar), and a gas cap forms above that height.

Centrifuge: ethanol–water at 20,000 rpm

An ethanol–water liquid at its bubble point (\(x_{\text{ethanol}} = 0.5\), 350 K, bar) is in contact with its vapor at \(r = 0.05\) m and fills the rotor out to \(r = 0.10\) m. The model is the ideal-solution route with user-typed vapor-pressure relations and liquid molar volumes.

At the wall the liquid is at about bar and slightly depleted in ethanol, the lighter component. Its bubble pressure is still well below this, so the wall region is a compressed liquid. The vapor–liquid diagram at any one radius is the ordinary one: the field changes where states are found, not the equilibrium between coexisting phases.

Limitations and roadmap

Current limitations

  • The ideal-solution route ignores liquid non-ideality. It cannot predict azeotropes, and it is quantitatively poor for strongly non-ideal mixtures such as sugar–water.
  • van der Waals mixing rules with a single \(k_{ij}\) work well for hydrocarbons, less well for polar mixtures.
  • Near a mixture critical point, bubble and dew calculations can converge only to the trivial solution. The tool reports this rather than returning a wrong answer.
  • Only two-phase equilibria are handled: vapor–liquid, and liquid with a pure solid. Diagrams and solid–liquid compositions are for binaries; flash and saturation points work for any number of components.
  • Field profiles are isothermal. When two phases are given at the reference position, the interface is placed there.

Next steps

  • Plotting module: Pxy, Txy and solid–liquid diagrams, field profiles, and 3D P–T–x and Gibbs-energy surfaces.
  • Validation against experimental VLE data, with average absolute deviations and fitting of \(k_{ij}\).
  • An activity-coefficient model (NRTL or Wilson) in the Gibbs form, for non-ideal liquids.
  • Liquid–liquid and three-phase equilibrium, using the stability criteria from the fundamental equation.
  • Ternary diagrams for three-component systems.
  • An interface, and optional automatic import of property data from published tables.

Getting started

You need Python 3.9 or later with NumPy and SciPy.

git clone https://github.com/Fang099/phase-equilibrium-calculator.git
cd phase-equilibrium-calculator
pip install -r requirements.txt

python input_checker.py examples/sugar_water.txt        # check an input
python equilibrium_solver.py examples/sugar_water.txt   # check and solve it

To describe your own system, copy one of the files in examples/ and edit it. To run the test suites:

python thermo_models.py
python equilibrium_solver.py

From Python or Colab

In Colab, run !git clone https://github.com/Fang099/phase-equilibrium-calculator.git and %cd phase-equilibrium-calculator in the first cell. Then:

from input_checker import check_input
from thermo_models import build_system
from equilibrium_solver import solve, print_results

text = open("examples/sugar_water.txt").read()
print(check_input(text))            # verdict and what is missing

system = build_system(text)         # phase models (raises if insufficient)
results = solve(system)             # list of Result objects
print_results(system, results)
