Getting started

You need Python 3.9 or later with NumPy and Matplotlib. SciPy is used if installed and is not required.

git clone https://github.com/Fang099/phase-equilibrium-calculator.git
cd phase-equilibrium-calculator
pip install -r requirements.txt

Each stage can be run on an input file:

# is the information sufficient, and what would be calculated?
python input_checker.py examples/database_ethanol_water_nrtl.txt

# check, solve and print tables
python equilibrium_solver.py examples/database_ethanol_water_nrtl.txt

# check, solve and save every figure as PNG in plots/
python plotter.py examples/database_ethanol_water_nrtl.txt

To run the test suites:

python thermo_models.py
python equilibrium_solver.py
python web_api.py

To open this website and the calculator on your own computer, with no internet needed:

python scripts/dev_server.py
# then open http://localhost:8000/

Input format

An input file lists what is known, one quantity per line, in any order, with units. Lines starting with # are comments. Properties of a compound are written name.property, and properties of a pair property(name1, name2).

components = ethanol, water
database = builtin              # look up whatever is not given below
activity = vanlaar
A(ethanol, water) = 1.68        # ln(gamma) of ethanol at infinite dilution in water
A(water, ethanol) = 0.92
T = 350 K
sweep = x                       # draw the diagram over all compositions

Without the database line, every property must be in the file. That is how the program is used for compounds that are not in the database: the examples for benzene–naphthalene and for the centrifuge work this way.

What to specify

You giveThe program calculates
T and sweep = xPxy diagram
P and sweep = xTxy diagram, with solid–liquid curves if melting data are given
x(L) and sweep = TP–T diagram at that composition
T and x(L)Bubble-point pressure and vapor composition
P and x(L)Bubble-point temperature
T or P, and x(V)Dew point
T, P and zFlash: both compositions and the vapor fraction
Any of these plus fieldThe same, with pressure and composition profiles along height or radius

A vapor pressure can be typed as a formula, for example water.Psat = exp(16.3872 - 3885.70/(T - 273.15 + 230.170)) [kPa, K]. Only arithmetic, the variable T and the functions exp, log, ln, log10 and sqrt are accepted.

Using it from Python

The full pipeline, from text to figures:

from input_checker import check_input
from thermo_models import build_system
from equilibrium_solver import solve, print_results
from plotter import plot_results

text = open("examples/database_ethanol_water_nrtl.txt").read()
print(check_input(text))            # verdict and what is missing

system = build_system(text)         # phase models (raises if insufficient)
results = solve(system)             # list of Result objects
print_results(system, results)
figures = plot_results(system, results)   # {name: matplotlib Figure}

The interface the calculator page uses is also plain Python. It takes a small dictionary and returns one list per variable, in kelvin and bar:

import web_api

out = web_api.compute({"components": ["acetone", "chloroform"],
                       "model": "nrtl", "hold": "T", "T": 323.15})
out["columns"]["x1"], out["columns"]["P"], out["columns"]["gamma1"]
out["azeotrope"]        # {'x1': ..., 'P': ...} or None
out["input_text"]       # the input file this request stands for

Code reference

input_checker.py

check_input(text)
Parse and check an input. Returns a Report: the verdict, one entry per equilibrium, and the parsed input in SI units.
parse_input(text)
Parsing, unit conversion and database lookup only.
psat(props, T)
Vapor pressure in Pa from whichever source was given.

compound_db.py

find(name)
A compound record by name, id or CAS number.
pair(a, b)
NRTL parameters and Peng–Robinson \(k_{12}\) for a pair, if the database has them.
sources()
The citation behind each source tag.

thermo_models.py

CubicEOS
vdW, SRK or PR: helmholtz_res(T, V, n), pressure, ln_phi_TV, z_roots(T, P, x), molar_volume, ln_phi(T, P, x, phase).
Margules, VanLaar, NRTL
Activity models: ge_rt(T, x) and ln_gamma(T, x).
EOSPhase, SolutionLiquid, IdealGasPhase, PureSolidPhase
Phase models with one interface: ln_f(T, P, x), ln_phi, molar_volume.
Field
potential(pos) for gravity or centrifugal fields.
build_system(text)
Run the checker and build the phase models for each equilibrium that can be calculated.

equilibrium_solver.py

saturation(L, V, z, beta, T=, P=)
Unknown \(T\) or \(P\) at a given vapor fraction. bubble_P, bubble_T, dew_P and dew_T are shortcuts.
flash_TP(L, V, T, P, z)
Isothermal flash for any number of compounds.
vle_diagram(L, V, T= or P=)
Binary Pxy or Txy diagram, with .azeotrope and .three_phase when found.
diagram_properties(L, V, diagram)
K-values, activity coefficients, fugacities, fugacity coefficients and Gibbs energies at every point.
pt_envelope(L, V, z)
Bubble and dew pressure against temperature at fixed composition.
activity_coefficients, liquid_stability, point_properties
The same quantities at a single state.
sle_temperature, sle_composition, sle_curve, eutectic
Solid–liquid equilibrium with a pure solid.
column_profile(system, L, V, point)
Pressure, composition and phase along height or radius.
solve(system)
Run whatever the input asks for. print_results prints it as tables.

plotter.py

plot_results(system, results)
Every relevant figure, as {name: Figure}. save_figures writes PNG files.

web_api.py

catalog()
Compounds, models and sources offered by the calculator.
pair_defaults(a, b)
Starting parameter values and sensible ranges for a pair.
build_input(request)
The input file a calculator request stands for.
compute(request)
Run a request through the whole pipeline and return columns of results.

Compound data and sources

The database holds compounds, NRTL parameters for pairs and a Peng–Robinson \(k_{12}\) for pairs. It was generated on from the tables cited below. Every value in data/compounds.json carries a tag naming its source, and the calculator shows the values and sources for the selected pair under "Compound data and sources".

The values are reproduced from the cited sources for teaching use. Check them against the original publication before relying on them.

Antoine equation: \(\log_{10}(P^{\mathrm{sat}}/\text{Pa}) = A - B/(T/\text{K} + C)\), valid between the two temperatures listed.

Adding compounds

The database is built to grow. data/compound_list.csv has one row per compound:

id,name,formula,cas,family
acetonitrile,Acetonitrile,C2H3N,75-05-8,nitrile

After adding rows, fetch the two libraries' data files and run the build script. It looks up each CAS number, collects the pair parameters that exist for the new set, and rewrites data/compounds.json:

git clone --depth 1 https://github.com/CalebBell/chemicals
git clone --depth 1 https://github.com/CalebBell/thermo
python scripts/build_compound_db.py --chemicals chemicals --thermo thermo
python scripts/build_site.py

The source tables cover about a thousand compounds for critical constants and several hundred for Antoine constants, so most common liquids can be added this way. A compound that is in neither can still be used by writing its properties directly in an input file.

Rebuilding this website

The pages are written in site/pages/ and share one layout, site/layout.html. One script regenerates everything in docs/, which GitHub Pages serves:

python scripts/build_site.py           # everything
python scripts/build_site.py --pages   # only the pages, after editing text

The full run copies the Python modules to docs/py/ for the calculator, recomputes every number and chart on the pages, redraws the gallery images, and renders the pages. Run it after any change to the code so the site stays in step.
